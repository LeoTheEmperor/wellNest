# WellNest — Mental Health Check-In Platform

A full-stack web application for mental health check-ins, built solo with a React
frontend and Flask backend.

## What it does
- Chat-based check-in interface for users to log how they're feeling
- Mood tracking over time
- A dedicated psychiatrist-facing view for monitoring patient check-ins
- Backend services for response generation and mood analysis

## Tech stack
- **Frontend:** React (Vite), JavaScript
- **Backend:** Flask, Python
- **Database:** SQLite

## Running locally

Backend:
\`\`\`
python start_backend.py
\`\`\`

Frontend:
\`\`\`
npm install
npm run dev
\`\`\`
